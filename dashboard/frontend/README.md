# HDX SSD Pipeline Dashboard

A clean, simple dashboard for processing humanitarian datasets with AI models.

## Features

- **Run Pipeline**: Upload and process datasets with AI models
- **Results**: View and download processed reports
- **Analytics**: Monitor pipeline performance and metrics

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

## Project Structure

- `app/` - Next.js app router
- `src/components/` - React components
- `src/services/` - API service functions
- `src/types/` - TypeScript type definitions

## Tech Stack

- Next.js 16.1.2
- React 19
- TypeScript
- Tailwind CSS
- Lucide React (icons)
